# InterpLab · 口译自学训练与复盘工作台

浏览器端单用户口译训练工作台，覆盖**交替传译**、**带稿同传**、**无稿同传**、**影子练习**四种训练形态，以「智能分段 — 双轨记录 — 结构化复盘 — 个人成长追踪」为主轴。

> 所有素材、录音、复盘记录默认仅保存在**本机浏览器**（IndexedDB），不上传任何服务器。

## 功能

| 模块 | 能力 |
|---|---|
| 素材准备 | 上传音频（MP3/WAV/M4A）与**视频（MP4/MOV/WebM）**、波形预览、首尾静音裁剪、标签与难度标注、语速估算 |
| 素材导入 | 拖拽上传、**文件夹批量导入**、**直链下载导入**、网盘文件导入（见下方说明） |
| 智能分段 | VAD 静音检测 +「期望时长 ± 浮动」内按语义边界切分，边界置信度可见、可拖拽/合并/拆分 |
| 交传训练 | 逐段「听—记—译—录」、变速不变调、倒计时录音、数字笔记板 |
| 带稿同传 | 稿件/字幕对齐、随时间戳高亮滚动、术语高亮、隐藏文本、遮挡训练 |
| 无稿同传 | 极简界面、EVS 目标提示、自报告标记、干扰音 |
| 影子练习 | 源语/译语跟述、音位/片语、目标 EVS 与偏差曲线 |
| 复盘工作台 | 双轨波形严格对齐、源语/译语/混合/双耳分听、14 类问题锚点、可解释自动线索、视频回放 |
| 播放控制 | 全站统一倍速：0.25 / 0.5 / 0.75 / 1 / 1.25 / 1.5 / 1.75×，音频与视频同步变速不变调 |
| 个人成长 | 多轮趋势、问题分布、训练目标、连续天数与徽章 |
| 记录导出 | 训练记录 CSV、标记明细 CSV、全量 JSON、复盘报告（文本/PNG/打印 PDF） |

## 本地运行

```bash
cd frontend
pnpm install
pnpm dev        # http://localhost:5173
```

生产构建：

```bash
cd frontend
pnpm build      # 产物在 frontend/dist
pnpm preview
```

> **必须通过 http(s) 访问**，直接双击 `index.html` 无法使用录音与本地数据库。
> 录音需要浏览器授予麦克风权限，非 HTTPS 的远程地址会被浏览器拦截。

## 部署到 GitHub Pages

仓库已内置自动部署工作流 `.github/workflows/deploy.yml`：推送到 `main` 即自动构建并发布。

1. 在 GitHub 新建仓库（建议 public，Pages 免费额度不受限）；
2. 推送代码：

```bash
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git branch -M main
git push -u origin main
```

3. 打开仓库 **Settings → Pages**，把 **Source** 设为 **GitHub Actions**；
4. 等 Actions 里的 `Deploy InterpLab to GitHub Pages` 跑完，访问
   `https://<你的用户名>.github.io/<仓库名>/`。

`vite.config.ts` 里 `base: './'` 使用相对路径，因此无需按仓库名额外配置子路径。

## 技术说明

- 前端：Vite + React 19 + TypeScript + Tailwind CSS v4 + shadcn/ui + Recharts
- 音频：Web Audio API / MediaRecorder 采集，Canvas 波形渲染，双轨播放器保证时间轴同步
- 存储：IndexedDB（`idb`），音频与结构化数据分离存储
- 无后端依赖：分段与评估线索全部在浏览器端计算

### 视频素材

视频与音频走同一套内核：`decodeAudioData` 解析音轨生成波形，VAD 分段、变速、双轨复盘全部复用；
画面由 `<video>` 元素承载（`VideoStage`），音频仍经统一播放器输出，因此**不存在两份声音**。

若某个视频的音轨无法解码（少见容器/编码），系统会退化为「按视频时长等分分段 + 无波形」，
并在素材上标记，仍可正常播放与训练。

### 关于网盘导入

素材库提供三种导入方式：**拖拽/上传**、**文件夹批量**、**直链下载**（填 http(s) 直链直接抓取）。

百度网盘、阿里云盘的**个人账号挂载暂不可用**，原因是架构限制而非未实现：

- 两家开放平台都要求「OAuth 授权码 → 换 access_token」，换取时必须携带 `app_secret` 并做服务端签名；
- 本平台是纯前端站点（无服务器），把 secret 放进前端等于公开泄露；
- 两家的文件下载接口均未返回允许跨域的响应头（CORS），浏览器端无法直接拉取。

要真正支持挂载，需要额外部署一个仅做「换 token + 文件流转发」的轻量后端（约 100 行），
前端已预留入口，接入后即可启用。当前请使用「网盘下载到本地 → 文件夹导入」这一条路径。

### 关于自动评估线索

按 PRD 约束，自动指标**只提供线索、不给出总分**，措辞为「线索/参考信号」，并明确说明不能替代自我判断：

- **流利度**：停顿次数、平均停顿、发声时间比、长停顿位置（由录音能量包络计算）
- **覆盖率**：源语关键实体在译语转写中的命中情况
- **忠实度**：内容词重叠、数字匹配、高风险片段

覆盖率与忠实度需要「源语文本（稿件/字幕）」+「译语转写（可手填）」，缺失时界面会明确告知原因而非给出误导性数值。

## 数据与隐私

- 单用户产品，无教师端、班级、任务布置、互评、公开素材库与社交入口；
- 提供删除单条录音、删除素材及关联记录、删除全部数据入口；
- 支持导出训练记录与复盘报告用于归档迁移；
- 清理浏览器数据会导致本地内容丢失，请定期导出备份。
